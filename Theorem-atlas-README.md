# Theorem Atlas

An interactive map of the results in the [`VerifiedMechanisms/rs-takehome`](https://github.com/VerifiedMechanisms/rs-takehome) repository.

**[Open the Theorem Atlas](https://ben-meiring.github.io/rs-takehome/)**

Default topic views show only landmark theorems with many dependency connections. Use **Show all results** or the search bar to find the remaining theorems.

## How to use it

- Select a topic to view its main theorem dependencies.
- Click a theorem to see its prerequisites and downstream uses.
- Use **Show exact theorem claim** to read its statement.
- Use **View proof** to open the proof in the repository.
- Use **Research goals** or **Refuted hypotheses** to explore unresolved and disproved claims.
- Drag, zoom, or reset the graph to navigate it.

Results marked **Lean certified** have machine-checked formalizations. Dashed connections represent compressed relationships or inferred proof obligations.
